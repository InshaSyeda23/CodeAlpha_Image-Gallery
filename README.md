# CodeAlpha_Image-Gallery

## Project Overview
This project is a responsive **Image Gallery Web Application** built using **HTML, CSS, and JavaScript**.  
The gallery displays multiple images in a structured grid layout and allows users to interact with them through different features such as filtering, lightbox preview, navigation buttons, hover effects, and responsive design.

The purpose of this project is to demonstrate how front-end technologies can be used to create an interactive and visually appealing gallery.

---

## Gallery Layout using HTML & CSS
- The gallery structure is created using **HTML**.
- The layout is designed using **CSS Grid**.
- Images are arranged in a clean grid format.
- Each image contains a caption or title.
- Proper spacing and alignment are maintained for a neat visual appearance.

---

## Lightbox Image View
- Clicking on any image opens it in a **lightbox preview**.
- The selected image appears in a larger size.
- The background becomes darker to focus on the image.
- A close button allows users to exit the preview easily.

---

## Navigation Buttons (Next / Previous)
- Users can navigate between images inside the lightbox.
- **Next and Previous buttons** are used to move through images.
- This functionality is implemented using **JavaScript**.
- It improves user experience by allowing quick image browsing.

---

## Hover Effects and Smooth Transitions
- Images include **hover animations** for better interaction.
- When hovering over an image:
  - The image slightly **zooms in**.
  - A **shadow effect** appears.
  - The image caption slides into view.
- **CSS transitions** are used to keep animations smooth.

---

## Responsive Design
- The gallery layout is fully **responsive**.
- It adapts to different screen sizes such as:
  - Desktop
  - Tablet
  - Mobile
- **CSS Media Queries** adjust the grid layout based on screen width.
- This ensures the gallery remains usable on all devices.

---

## Image Filtering
- The gallery includes **category-based filtering**.
- Users can filter images using buttons such as:
  - All
  - Portraits
  - Nature
- JavaScript dynamically shows or hides images based on the selected category.
- This helps users easily find specific types of images.

---

## Technologies Used
- **HTML5** – Page structure
- **CSS3** – Styling, layout, and animations
- **JavaScript** – Interactivity and functionality

---

## Conclusion
This project demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive and responsive image gallery.  
The use of layout techniques, animations, filtering, and responsive design helps provide a modern and engaging user experience.
